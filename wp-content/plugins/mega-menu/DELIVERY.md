## ⚡ Quick Start (3 Steps)

### 1. Activate the Plugin
- Go to WordPress Dashboard
- Plugins → Find "Mega Menu" → Click Activate

### 2. Create a Menu
- Click "Mega Menu" in left menu
- Enter title (e.g., "Sports")
- Select a page
- Click "Create Menu"

### 3. Use the Shortcode
- Click "+ Add Row" and fill in details
- Copy the shortcode from the menu header
- Paste on any page
- Done! Your menu appears!

## 💾 How Data is Stored

Your menus are stored in two WordPress database tables:

**wp_mega_menus**
- Menu name
- Associated page
- Auto-generated shortcode

**wp_mega_menu_items**
- Menu rows with headings
- Links for each row
- Image IDs
- Display order

## 📝 Usage Example

### Creating a "Sports" Menu

1. **Create**: Menu title = "Sports", Page = Sports page
2. **Add Row 1**:
   - Heading: "Football"
   - Link: "https://example.com/football"
   - Images: Upload 2-3 football images
3. **Add Row 2**:
   - Heading: "Basketball"
   - Link: "https://example.com/basketball"
   - Images: Upload 2-3 basketball images
4. **Use Shortcode**: 
   ```
   [mega_menu shortcode="sports_abc123"]
   ```
   Paste on any page!
