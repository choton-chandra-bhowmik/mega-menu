# Mega Menu Plugin - Quick Start Guide

## 🚀 Quick Start in 5 Minutes

### Step 1: Activate the Plugin
1. Go to **WordPress Dashboard**
2. Click **Plugins** from the left menu
3. Find **Mega Menu** and click **Activate**

### Step 2: Create Your First Menu
1. Click **Mega Menu** in the left dashboard menu (new menu added)
2. In the left panel, enter:
   - **Menu Title**: "Sports" (or your menu name)
   - **Select Page**: Choose any page from the dropdown
3. Click the **Create Menu** button

### Step 3: Add Menu Items
1. In the right panel, you'll see your new menu
2. Click **+ Add Row** to add your first item
3. Fill in the details:
   - **Heading**: Type a title (e.g., "Football")
   - **Link**: Paste a URL (optional)
   - Click **Upload Images** to add images
4. Click **Save**

### Step 4: Copy Your Shortcode
1. Look at the menu header - you'll see the shortcode in the **Shortcode** field
2. Click **Copy** to copy it to your clipboard
3. Go to any page and paste this shortcode where you want the menu to appear

### Step 5: View Your Menu
1. Visit the page where you pasted the shortcode
2. Your mega menu will appear with all the items and images you added!

## 📝 Common Tasks

### Add More Items to a Menu
- Click **+ Add Row** again
- Fill in the new item details
- Click **Save**

### Edit an Item
- Click in any field to edit
- Click **Save** to save changes

### Remove an Item
- Click the **Delete** button for that item

### Add Multiple Images to an Item
- Click **Upload Images**
- Select multiple images from your media library
- They'll appear as thumbnails

### Remove an Image
- Hover over the image thumbnail
- Click the **×** button

### Delete an Entire Menu
- Click the **Delete Menu** button at the top of the menu

## 💡 Pro Tips

1. **Create Multiple Menus**: You can create different menus for different pages (Sports, Franchise, Partners, etc.)

2. **Reuse Shortcodes**: Copy a menu shortcode and paste it on multiple pages to display the same menu everywhere

3. **Link to External Sites**: Use full URLs in the Link field to link to external websites (e.g., `https://example.com/page`)

4. **Link to Internal Pages**: Use relative URLs to link to other pages on your site (e.g., `/about` or `https://yoursite.com/about`)

5. **Image Gallery**: Upload multiple images per row to create an image gallery within the menu

## ❓ FAQ

**Q: Can I add the same menu to multiple pages?**
A: Yes! Copy the shortcode and paste it on as many pages as you want.

**Q: Can I change the menu layout?**
A: The plugin uses a responsive grid layout. You can customize it with CSS if needed.

**Q: How many images can I add per item?**
A: Unlimited! Add as many as you need.

**Q: Can I change the order of items?**
A: Currently items are displayed in the order you add them. To reorder, delete and re-add items.

**Q: Where is my data stored?**
A: All menu data is stored in your WordPress database. It's safe and backed up with your database.

**Q: Can I use the same shortcode on different pages?**
A: Yes! One shortcode can be used on multiple pages and pages will display the exact same menu.
